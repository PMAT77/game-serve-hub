## 一、项目概述与核心目标
### 1.1 产品定位
一款轻量级、开箱即用的 Web 管理面板，专为已有 VPS / 独立服务器的 Steam 游戏玩家设计，提供零命令行的游戏服务器部署、管理和维护体验。
### 1.2 核心价值主张
- ✅ **5 分钟开服**：从面板安装到游戏服务器运行，全程无需输入 Linux 命令
- ✅ **完全中立**：支持任何厂商的云服务器 / 物理机，绝不强制捆绑销售
- ✅ **Steam 原生**：深度集成 SteamCMD 和 Steam 创意工坊，针对 Steam 游戏优化
- ✅ **中文友好**：全中文界面、国内网络加速、新手引导完善
### 1.3 免费版核心目标
满足单人 / 2-8 人小团体玩家的基础开服需求，建立产品口碑，为后续付费版转化奠定基础。
### 1.4 免费版与付费版边界（明确限制）
| 功能维度 | 免费版 | 个人付费版（后续） |
|---|---|---|
| 服务器数量 | 最多管理 1 台物理 / VPS 服务器 | 最多 3-10 台 |
| 游戏实例数 | 单服务器最多运行 2 个游戏实例 | 无限制 |
| 备份功能 | 仅支持手动本地备份，最多保留 3 个 | 自动定时备份、异地备份、无限保留 |
| Mod 管理 | 基础一键安装 / 卸载 | 批量更新、冲突检测、配置可视化 |
| 通知功能 | 无 | Discord / QQ 机器人通知 |
| 多用户 | 无 | 多用户协作、权限分级 |
| 技术支持 | 社区支持 | 优先邮件支持 |

## 二、免费版功能需求详解
### 2.1 系统基础功能模块（MVP 必做）
#### 2.1.1 面板一键安装与初始化
- 提供单命令一键安装脚本，支持 Ubuntu 20.04+ / Debian 11+ / CentOS 8+（优先支持前两者）
- 提供 Windows Server 2019+ 一键安装包（`.exe` 格式）
- 安装过程自动检测并安装依赖（Docker、SteamCMD、Node.js 等）
- 自动配置防火墙规则，开放必要端口
- 初始化完成后生成随机管理员账号密码和访问地址
- 首次登录强制修改密码
#### 2.1.2 用户认证与系统设置
- 单用户账号系统（免费版不支持多用户）
- 登录 / 登出 / 记住密码功能
- 基础系统设置：
  - 面板访问端口修改
  - 管理员密码修改
  - 界面语言切换（仅中文）
  - 主题切换（明暗模式）
  - 面板自动更新开关
- 系统信息展示：
  - 服务器 CPU / 内存 / 磁盘使用率
  - 操作系统版本
  - 面板版本号
  - Docker 运行状态
#### 2.1.3 服务器节点管理
- 支持添加本地节点（面板所在服务器）
- 自动检测节点硬件信息和可用资源
- 显示节点当前运行的游戏实例列表和资源占用
- 提供节点重启 / 关机按钮（需二次确认）
### 2.2 游戏实例管理模块（MVP 必做）
#### 2.2.1 游戏服务端一键安装
- 游戏市场页面展示已支持的游戏列表（含封面和简介）
- 每个游戏提供“一键安装”，点击后自动执行：
  - 下载并安装 SteamCMD
  - 匿名登录 Steam（或提示输入 Steam 账号，用于需购买游戏）
  - 下载最新版游戏服务端
  - 自动生成默认配置文件
  - 创建 Docker 容器并配置网络
- 安装过程实时显示进度条和日志
- 支持安装中断和断点续传
- 支持游戏服务端手动更新
#### 2.2.2 游戏实例生命周期管理
- 实例列表展示：游戏名称、状态（运行 / 停止 / 安装中）、CPU / 内存占用、运行时长
- 核心操作：启动 / 停止 / 重启 / 删除实例（均需二次确认）
- 实例详情页：
  - 实时状态监控（CPU、内存、网络流量）
  - 服务器连接地址和端口显示
  - 一键复制连接命令
  - 运行时长和在线玩家数显示
#### 2.2.3 游戏控制台
- 实时显示游戏服务器控制台输出
- 支持向服务器发送命令（如 `/say`、`/save` 等）
- 控制台日志自动滚动
- 支持清空日志和复制日志内容
### 2.3 Mod 管理模块（MVP 必做，核心竞争力）
#### 2.3.1 Steam 创意工坊集成
- 集成 Steam 创意工坊 API，支持按游戏搜索 Mod
- 显示 Mod 名称、作者、订阅数、更新时间和简介
- 支持一键安装 / 卸载 Mod
- 支持批量选择安装多个 Mod
- 自动处理 Mod 依赖关系（基础版）
#### 2.3.2 Mod 列表管理
- 已安装 Mod 列表展示，带启用 / 禁用开关
- 支持调整 Mod 加载顺序（拖拽排序）
- 显示 Mod 版本号和最后更新时间
- 支持手动上传本地 Mod 文件（`.zip` 格式）
### 2.4 配置管理模块（MVP 必做）
#### 2.4.1 可视化配置编辑器
- 针对每个游戏，将复杂配置文件（`.cfg` / `.json` / `.toml`）转换为可视化表单
- 配置项分类展示（基础设置、游戏设置、世界设置、玩家设置等）
- 每个配置项附带中文说明和默认值提示
- 支持一键恢复默认配置
- 配置修改后自动验证格式并错误提示
- 保存配置后提示是否重启服务器生效
#### 2.4.2 高级配置（可选，MVP 后迭代）
- 提供原始配置文件编辑器（带语法高亮）
- 支持配置文件导入 / 导出
### 2.5 备份与恢复模块（MVP 必做）
#### 2.5.1 手动备份
- 支持一键备份游戏世界和配置文件
- 备份列表展示：备份时间、备份大小、备注
- 支持备份重命名和添加备注
- 支持从备份恢复游戏实例
- 免费版限制：最多保留 3 个备份文件，超出自动删除最早备份
### 2.6 文件管理模块（MVP 必做）
- 简易 Web 文件管理器，支持浏览游戏服务器目录
- 支持文件上传 / 下载 / 删除 / 重命名
- 支持创建文件夹
- 支持文本文件在线编辑（带语法高亮）
- 限制：仅允许访问当前游戏实例目录，禁止访问系统根目录
### 2.7 新手引导与帮助模块（MVP 必做）
- 首次登录弹出 5 步快速上手引导
- 每个功能页面提供“帮助”按钮，点击显示使用说明
- 常见问题（FAQ）页面
- 一键跳转官方社区（QQ 群 / Discord）获取帮助

## 三、MVP 里程碑规划（3 个月 / 90 天）
### 第一阶段：基础框架搭建（第 1-4 周，28 天）
- **目标**：完成面板核心架构和基础功能，能够运行并管理一个简单游戏实例
| 时间 | 任务 | 交付物 |
|---|---|---|
| 第 1 周 | 技术选型确认、项目初始化、开发环境搭建 | 技术栈文档、项目骨架代码 |
| 第 2 周 | 用户认证系统、系统设置模块、服务器节点管理 | 可登录的面板界面、系统信息展示 |
| 第 3 周 | Docker 集成、游戏实例生命周期管理框架 | 能够创建 / 启动 / 停止 / 删除 Docker 容器 |
| 第 4 周 | 游戏控制台功能、基础文件管理器 | 能够查看控制台输出、发送简单命令 |
**技术栈确认：**
- 前端：Vue 3 + Vite + Element Plus + Tailwind CSS
- 后端：Node.js + Express + Socket.IO（实时通信）
- 数据库：SQLite（MVP 阶段轻量部署）
- 容器化：Docker + Docker Compose
- 核心依赖：`steamcmd`、`node-docker-api`
### 第二阶段：核心游戏支持与 Mod 管理（第 5-8 周，28 天）
- **目标**：支持 3 款热门 Steam 游戏，完成核心 Mod 管理功能
| 时间 | 任务 | 交付物 |
|---|---|---|
| 第 5 周 | SteamCMD 集成、游戏服务端自动安装框架 | 能够自动下载和安装 Steam 游戏服务端 |
| 第 6 周 | 完成饥荒联机版完整适配（配置可视化 + 基础 Mod 支持） | 可一键创建饥荒联机服务器并修改配置 |
| 第 7 周 | Steam 创意工坊 API 集成、Mod 一键安装 / 卸载 | 可从创意工坊搜索并安装 Mod |
| 第 8 周 | 完成泰拉瑞亚和 Valheim（英灵神殿）适配 | 支持 3 款核心游戏一键开服 |
**优先级说明：**
1. 饥荒联机版（需求最大，Mod 生态最丰富）
2. 泰拉瑞亚（用户基数大，配置相对简单）
3. Valheim（热门生存游戏，自建服务器需求高）
### 第三阶段：功能完善与测试上线（第 9-12 周，28 天）
- **目标**：完成剩余免费版功能、全面测试并发布首个公开版本

## 四、非功能需求
### 4.1 性能要求
- 面板启动时间 < 5 秒
- 页面加载时间 < 2 秒
- 单服务器运行 2 个游戏实例时，面板 CPU 占用 < 5%，内存占用 < 200MB
- 游戏控制台实时输出延迟 < 1 秒
### 4.2 兼容性要求
- **服务器端**
  - 优先支持：Ubuntu 20.04 LTS、Ubuntu 22.04 LTS、Debian 11、Debian 12
  - 次要支持：Windows Server 2019、Windows Server 2022
- **客户端**
  - 支持 Chrome、Edge、Firefox 最新版浏览器
  - 响应式设计，支持手机和平板访问
### 4.3 安全性要求
- 所有密码使用 `bcrypt` 加密存储
- 所有 API 接口进行身份验证
- Docker 容器运行在非 root 用户下
- 禁止用户访问系统敏感目录
- 输入内容严格过滤，防止 XSS 与命令注入攻击
### 4.4 易用性要求
- 从安装面板到创建第一个游戏服务器，全程不超过 5 分钟
- 所有核心操作不超过 3 次点击
- 所有配置项都有清晰中文说明
- 错误提示友好，并提供解决方案

## 五、验收标准
### 5.1 核心流程验收
1. 用户在全新 Ubuntu 22.04 服务器执行一键安装脚本，10 分钟内完成安装
2. 用户登录面板，点击“创建服务器”，选择饥荒联机版并执行“一键安装”
3. 15 分钟内（视网络速度）服务端安装完成并自动启动
4. 用户可在面板修改服务器名称、密码、世界设置等配置
5. 用户可从创意工坊搜索并安装 Mod，启用后重启服务器生效
6. 用户可手动备份游戏世界，并在需要时恢复
7. 用户可查看游戏控制台并发送命令
### 5.2 Bug 验收标准
- 无严重 Bug（导致面板崩溃、数据丢失、服务器无法启动）
- 无阻塞性 Bug（核心功能无法使用）
- 一般 Bug 数量不超过 10 个
