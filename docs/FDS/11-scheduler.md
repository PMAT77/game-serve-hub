# FDS-11：计划任务

- 里程碑：M3
- 优先级：P1
- 状态：规划态

## 1. 背景与目标

提供可配置的自动化任务能力，减少重复人工运维操作。

## 2. 角色与前置条件

- 角色：管理员
- 前置：实例与系统模块可提供可调用动作

## 3. 功能范围

- 定时执行实例级任务（启停、更新检查、备份触发）
- 定时执行系统级任务（清理、巡检）

## 4. 功能清单

- 任务创建/启停（Community）
- 执行历史查询（Community）
- 失败重试与通知（Pro 规划）

## 5. 接口与输入输出（规划）

- `POST /app/schedules`
- `GET /app/schedules`
- `POST /app/schedules/:id/run`

输入示例：

```json
{
  "name": "nightly-backup",
  "cron": "0 3 * * *",
  "action": "instance.backup",
  "targetId": "instance-001",
  "enabled": true
}
```

## 6. 业务规则

- 任务动作必须来自白名单。
- 同一目标互斥任务需避免并发冲突。

## 7. 异常与边界

- Cron 非法 -> 阻止保存
- 执行超时 -> 标记失败并记录上下文

## 8. 非功能要求

- 任务执行日志需可追溯
- 调度器重启后任务状态可恢复

## 9. 验收标准

- 任务可按计划触发
- 执行结果可查询
- 失败场景可定位原因

## 10. 后续里程碑

- 任务编排模板
- 依赖图与执行窗口控制
