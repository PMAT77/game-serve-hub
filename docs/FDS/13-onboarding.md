# FDS-13：新手引导

- **里程碑**：M2  
- **优先级**：P1  
- **状态**：未实现

## 1. 背景与目标

降低首次使用门槛，在 5 步内引导完成「安装 → 登录 → 创建实例 → 启动 → 进服」，并可从帮助中心再次打开。

## 2. 用户角色与前置条件

- 首次登录或用户主动点击「新手引导」。  
- 安装可由脚本完成（引导从登录后开始）或包含安装说明页（外链 RUNBOOK）。

## 3. 用户故事

1. **作为**新用户，**我希望**按步骤被引导创建第一个 DST 服，**以便**不迷失在菜单中。

## 4. 流程（5 步）

| 步 | 标题 | 动作 | 完成条件 |
|----|------|------|---------|
| 1 | 欢迎 | 介绍面板能力 | 点击下一步 |
| 2 | 认识监控台 | 跳转或高亮监控台 | 访问过 /console/monitor |
| 3 | 创建实例 | 打开创建弹窗并提交 | 存在至少 1 实例 |
| 4 | 等待安装 | 说明安装耗时 | 实例 status ≠ installing |
| 5 | 启动并进服 | 启动 + 控制台/连接说明 | 实例 running 或用户跳过 |

支持 **跳过**、**不再提示**（localStorage）、**再次查看**（帮助菜单）。

## 5. 页面与信息架构

- 全局 `NModal` / 步骤条或 Spotlight 高亮（Naive UI `NTour` 若可用）。  
- 帮助入口：顶栏或系统设置页链接到文档与 FAQ。

## 6. 功能点清单

| 功能 | 版本 |
|------|------|
| 5 步引导 | Community |
| 跳过/重看 | Community |
| 上下文帮助图标（各页） | Community P1 |

## 7. 数据

- 无后端持久化；可选 `users.onboarding_done`（v1 可仅前端存储）。

## 8. 异常与边界

| 场景 | 行为 |
|------|------|
| 已有实例的老用户 | 默认不自动弹出 |
| 移动端窄屏 | 步骤条可滚动 |

## 9. 验收标准

- [ ] 新账号首次登录出现引导。  
- [ ] 跳过后不再自动弹出（除非点重看）。  
- [ ] 完成 Step3 后实例列表可见新实例。
