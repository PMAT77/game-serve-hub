## 3. 整体系统验收标准

- **功能完整性**：认证、实例生命周期、监控、控制台四大主链路可完成。
- **稳定性**：关键流程连续执行无阻断性错误。
- **可观测性**：日志、错误码、状态字段可支持排障。
- **一致性**：代码能力与文档状态一致。

## 4. 验收流程与方法

1. 准备环境：安装依赖、启动前后端、确保 Docker 可用。
2. 执行模块用例：按 FDS §9 与 [`M0-M1-REGRESSION.md`](M0-M1-REGRESSION.md) 逐项验证。
3. 执行端到端场景：登录 → 实例管理 → 创建并安装 → 启动 → 控制台 → 停止 → 删除。
4. 记录结果：通过/失败、日志、复现步骤、修复建议。
5. 回归验证：修复后重复关键路径直至通过。

服务端自动化：`pnpm test:server`（含 cluster/shard 等用例，**以当前命令输出为准**）。
