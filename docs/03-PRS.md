## 3. 关键功能详细描述（输入/输出/规则）

### 3.1 认证与权限

- **功能**：登录、登出、权限查询、改密、强制改密。
- **输入**：账号密码、旧密码与新密码、Token 头。
- **输出**：统一响应壳（`status/error/data/requestId`）。
- **规则**：
  - 未登录访问受保护接口返回未授权。
  - 首次登录可触发强制改密，未改密前限制敏感操作。
  - 权限码用于前端路由与菜单控制，API 细粒度 RBAC 后续增强。

### 3.2 节点与实例生命周期

- **功能**：节点注册、实例列表、创建、安装、启停、重启、更新、删除。
- **输入**：实例名称、节点ID、游戏编码、端口参数。
- **输出**：实例状态、安装进度、版本与更新信息。
- **规则**：
  - v1 仅支持 `local-node` 作为主运行节点。
  - 创建后进入安装流程，安装成功后可运行。
  - 删除实例时需清理运行资源与关联目录。

### 3.3 系统设置与资源监控

- **功能**：面板设置、SteamCMD 配置、系统信息、网络实时数据。
- **输入**：设置项、安装参数、查询条件。
- **输出**：资源快照、配置读写结果、网络指标。
- **规则**：
  - 配置持久化到系统设置存储。
  - 监控数据允许短周期轮询缓存。

### 3.4 实例控制台

- **功能**：日志读取、日志清空、命令发送、SSE 推送。
- **输入**：实例ID、命令字符串、游标参数。
- **输出**：日志片段、执行结果、推送流。
- **规则**：
  - 仅运行中的实例允许写命令。
  - 控制台日志需支持实时与回溯两种读取模式。

## 4. 异常场景处理逻辑

- **鉴权异常**：Token 失效或缺失 -> 返回未授权，前端清理会话并回登录页。
- **安装失败**：SteamCMD 或容器运行失败 -> 实例标记错误态，返回可读错误信息并保留日志。
- **资源不可用**：Docker 不可达或主机信息采集失败 -> 返回业务错误码并可重试。
- **并发冲突**：对同一实例重复执行互斥操作 -> 拒绝后续操作并给出状态提示。
- **外部依赖波动**：网络、镜像拉取失败 -> 提供重试与排障指引。

## 5. 非功能需求

### 5.1 性能

- 关键列表接口在常规规模下响应保持可交互。
- 指标查询采用采样与缓存，避免高频全量采集。

### 5.2 安全

- 密码安全存储（哈希），敏感接口鉴权必需。
- 限制危险路径访问与非法文件系统浏览。
- 错误响应不泄露敏感系统信息。

### 5.3 兼容性

- 支持 Windows 与 Linux 主流环境。
- 面板前端适配现代浏览器。

### 5.4 可扩展性

- 游戏适配器结构可扩展到多游戏。
- 模块化路由与文档化 FDS 支持增量演进。

## 6. 约束与依赖

- 强依赖 Docker 运行时与 SteamCMD 安装链路。
- 强依赖 SQLite 数据持久化（当前版本）。
- 受 DST 与平台网络策略约束。
