# FDS-02：节点与实例

- 里程碑：M0/M1
- 优先级：P0
- 状态：已实现（单节点，M0 已完成 2026-05-19）

## 1. 背景与目标

实现 DST 实例从创建到删除的生命周期闭环，作为产品核心能力。

## 2. 角色与前置条件

- 角色：具备实例管理权限的管理员
- 前置：本地节点已注册，SteamCMD 与 Docker 可用

## 3. 功能范围

- 本地节点注册与列表
- 实例创建、安装、启停、重启、更新、删除
- 安装日志与运行指标查询

## 4. 功能清单

- 实例列表检索（Community）
- 实例生命周期操作（Community）
- 安装日志追踪（Community）
- 远程节点与调度（Pro 规划）

## 5. 接口与输入输出

- 核心接口：`/app/node/*`、`/app/instance/*`
- 输入：实例信息、操作类型、实例 ID
- 输出：实例状态、进度、错误信息

## 6. 业务规则

- v1 以 `local-node` 为主执行节点。
- 安装中实例不可执行互斥操作。
- 删除实例前需完成停服与资源清理。

### 6.1 同机安装加速（depot seed）

创建或更新实例时，若目标目录尚无完整游戏文件，面板可 **从本机其他已停止实例复制游戏 depot**（除 `klei-storage` 外完整安装根：`data/`、`bin/`、`bin64/`、`mods/`、`linux64/`、`steamapps/` 等），跳过 Steam 全量下载；**不复制** `klei-storage/`（各实例存档与房间配置独立）。

供体（donor）须同时满足：

- 状态为 **stopped**（运行中实例不作为供体）
- 游戏文件完整（存在 DST 可执行文件、非空 `data/` 与 `appmanifest_343050.acf`）
- `updateAvailable === false`（本地 buildid 与远端一致）
- 非 installing / 无进行中的 SteamCMD 任务

复制失败或无可用供体时 **自动回退** SteamCMD `app_update 343050`。

环境变量（见 FDS-00、`panel.env.example`）：

- `GSH_INSTALL_SEED_ENABLED`：默认 `1`（开启）
- `GSH_INSTALL_DEFER_DST_IMAGE_PULL`：默认 `1`（安装结束不 pull DST 运行镜像，首次启动时拉取）

## 7. 异常与边界

- 路径非法或参数错误 -> 拒绝创建
- 运行时不可用 -> 操作失败并返回原因
- 状态冲突 -> 返回业务错误，提示当前状态

## 8. 非功能要求

- 操作过程可观测（日志、状态字段）
- 关键流程可重试且不会破坏数据一致性

## 9. 验收标准

- 完成实例创建到删除闭环
- 安装日志与状态一致
- 运行指标仅在运行态返回有效值
