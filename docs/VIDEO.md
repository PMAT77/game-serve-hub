## 录制与素材规范

- 分辨率 1920 × 1080、30 fps，终端字号 18，浏览器缩放 125%。
- 耗时的下载环节用加速播放并保留真实计时，不做跳过结果的剪辑。
- 演示服务器使用按量付费实例，录制完成后销毁；片中房间密码与管理员密码使用示例值，集群令牌一律不做展示。
- 界面截图放在 [`docs/images/`](images/)，界面改版时同步更新。

## 本项目当前不提供的能力

以下能力尚未提供，正在开发中，界面与文档都不要把它们当作可用功能：

- 玩家管理（白名单、黑名单、加管理员、踢人）与多用户权限隔离
- 文件管理与配置原始文件编辑（当前只有安装路径选择器）

另外两项属于产品边界，不在规划内：

- **Windows 部署**：本项目以 Linux 为目标平台，Windows 只用于本机开发调试，见[开发指南的平台定位](DEVELOPMENT.md#平台定位)。
- **多层世界**：当前支持地上与洞穴双分片，不支持两个以上的分片。

如果你需要多用户权限隔离、玩家管理，或者要在 Windows 上开服，**建议直接使用同类面板**，例如 [DMP 饥荒管理平台](https://github.com/miracleEverywhere/dst-management-platform-api) 或 [DST Admin Go](https://github.com/carrot-hu23/dst-admin-go)。它们的部署更简单，功能覆盖也更广；本项目更适合已经有一台服务器、不想被云厂商绑定、希望自行长期维护的场景。
