# FDS-08：文件管理

- 里程碑：M2
- 优先级：P1
- 状态：规划态

## 1. 背景与目标

提供实例沙箱内文件管理能力，支持运维排障与轻量编辑。

## 2. 角色与前置条件

- 角色：实例管理员
- 前置：实例目录可访问且路径边界明确

## 3. 功能范围

- 文件浏览、下载、上传
- 文本文件编辑
- 文件基础操作（重命名/删除/新建）

## 4. 功能清单

- 沙箱目录浏览（Community）
- 文本编辑与下载（Community）
- 大文件与断点续传（Pro 规划）

## 5. 接口与输入输出（规划）

- `GET /app/instances/:instanceId/files`
- `POST /app/instances/:instanceId/files/upload`
- `PUT /app/instances/:instanceId/files/content`

## 6. 业务规则

- 严格限制在实例沙箱路径内。
- 关键文件编辑需提示运行风险。

## 7. 异常与边界

- 越界路径 -> 拒绝访问
- 二进制文件 -> 不提供在线编辑

## 8. 非功能要求

- 文件操作日志可追溯

## 9. 验收标准

- 文件操作不越界
- 编辑保存后文件一致性可验证

## 10. 后续里程碑

- 批量文件操作
- 审计联动
