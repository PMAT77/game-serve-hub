# FDS-10：玩家与访问

- 里程碑：M2
- 优先级：P1
- 状态：规划态

## 1. 背景与目标

将玩家访问控制能力产品化，减少手工维护访问名单。

## 2. 角色与前置条件

- 角色：实例管理员
- 前置：Cluster 配置可用

## 3. 功能范围

- 管理员名单
- 白名单
- 封禁名单

## 4. 功能清单

- 名单维护（Community）
- 在线玩家辅助视图（规划）
- 规则策略增强（Pro 规划）

## 5. 接口与输入输出（规划）

- `GET /app/instances/:instanceId/access/:type`
- `PUT /app/instances/:instanceId/access/:type`
- 输入：名单项列表
- 输出：保存结果与生效提示

## 6. 业务规则

- 名单项需做格式校验。
- 与房间访问模式配置联动。

## 7. 异常与边界

- 非法 ID -> 拒绝提交
- 配置冲突 -> 给出修正提示

## 8. 非功能要求

- 变更需保留可审计记录（后续接模块 12）

## 9. 验收标准

- 名单可读写并体现在访问控制行为中

## 10. 后续里程碑

- 在线玩家态管理
- 临时策略与自动解禁
