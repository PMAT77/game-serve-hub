# FDS-08：文件管理

- **里程碑**：M2  
- **优先级**：P1  
- **状态**：未实现（仅有系统级目录浏览）

## 1. 背景与目标

在**实例沙箱**内浏览、上传、编辑文件，用于排查存档、手工放置 Mod 包等，不暴露宿主机任意路径。

## 2. 用户角色与前置条件

- 管理员权限。  
- 路径限制在 `{installPath}` 下（含 `klei-storage`）。

## 3. 名词

- **沙箱根**：实例 `install_path` 解析后的绝对路径（容器内路径）

## 4. 用户故事

1. **我希望**浏览存档目录，**以便**确认备份内容。  
2. **我希望**在线编辑小文本配置，**以便**快速热修。  
3. **我希望**上传限制大小的文件，**以便**导入自定义 lua（高级用户）。

## 5. 页面与信息架构

`/ops/files/:instanceId`：左侧目录树，右侧文件列表与编辑器。

操作：新建文件夹、重命名、删除、上传、下载。

## 6. 功能点清单

| 功能 | 版本 |
|------|------|
| 列目录 | Community |
| 下载 | Community |
| 删除/重命名/新建目录 | Community |
| 文本编辑（≤1MB 可配置） | Community |
| 上传（单文件大小限制） | Community |
| 断点续传大文件 | Pro / P2 |

## 7. 数据与 API

- 复用路径校验逻辑（禁止 `..`、敏感系统路径）  
- API：[API.md](../API.md) §9  
- 与 `/app/system/filesystem/*` 分离（后者仅安装路径选择）

## 8. 异常与边界

| 场景 | 行为 |
|------|------|
| 越界路径 | 403 |
| 编辑运行中关键文件 | 警告 + 建议停服 |
| 二进制文件 | 仅下载，不编辑 |

## 9. 验收标准

- [ ] 无法通过 `../` 访问沙箱外。  
- [ ] 编辑 server.ini 保存后内容与 FDS-04 一致。

## 10. 不在本期范围

- 多实例批量文件同步
