# FDS-05：Mod 管理

- 里程碑：M2
- 优先级：P1
- 状态：规划态

## 1. 背景与目标

提供可视化 Mod 管理，减少手动编辑配置的复杂度与出错率。

## 2. 角色与前置条件

- 角色：实例管理员
- 前置：实例安装完成，可访问 Workshop 相关资源

## 3. 功能范围

- Mod 搜索、安装、启用/禁用、排序
- 生成并维护 Mod 配置文件

## 4. 功能清单

- Mod 列表与状态管理（Community）
- 基础依赖提示（Community）
- 自动更新与批量策略（Pro 规划）

## 5. 接口与输入输出（规划）

- `GET /app/instances/:instanceId/mods`
- `POST /app/instances/:instanceId/mods/install`
- `PUT /app/instances/:instanceId/mods/:modId`

## 6. 业务规则

- 运行中安装/卸载需给出风险提示。
- 配置变更建议在停服窗口执行。

## 7. 异常与边界

- 上游 API 限流 -> 退避重试
- 安装失败 -> 保留错误上下文

## 8. 非功能要求

- 操作可审计（后续接模块 12）

## 9. 验收标准

- 支持 Mod 基础生命周期管理
- 配置文件生成与界面状态一致

## 10. 后续里程碑

- 冲突检测增强
- Mod 更新自动化
