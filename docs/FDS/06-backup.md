# FDS-06：备份管理

- **里程碑**：M2  
- **优先级**：P1  
- **状态**：未实现

## 1. 背景与目标

保护 Cluster 存档与关键配置，支持手动备份与恢复；Community 限制份数，Pro 提供自动化与云存储。

## 2. 用户角色与前置条件

- 实例存在；备份前建议停止所有 Shard（强提示，可选「热备份」标风险）。

## 3. 名词

- **备份包**：tar/zstd 归档，含 Cluster 目录 + 元数据（instanceId、时间、备注）

## 4. 用户故事

1. **我希望**一键备份当前世界，**以便**更新 Mod 前留底。  
2. **我希望**从列表恢复某天的档，**以便**回档误操作。  
3. **我希望** Pro 自动每天备份到云，**以便**磁盘故障不丢档。

## 5. 页面与信息架构

- 全局「运维 → 备份」按实例筛选，或实例 Tab「备份」。

| 列 | 说明 |
|----|------|
| 时间 | createdAt |
| 大小 | sizeBytes |
| 备注 | 可编辑 |
| 操作 | 恢复、删除、下载（可选） |

顶部：**创建备份**；Pro：**定时策略**入口。

## 6. 功能点清单

| 功能 | 版本 |
|------|------|
| 手动创建备份 | Community |
| 列表/备注/删除 | Community |
| 恢复 + 二次确认 | Community |
| 最多保留 3 份，超限删最早 | Community |
| 定时备份 | Pro |
| 云存储 S3/OSS/COS | Pro |
| 增量备份 | Pro / v1.x |

## 7. 数据与 API

- 表：`backups`  
- 存储：`/var/lib/game-server-hub/backups/{instanceId}/{backupId}.tar.zst`（规划）  
- API：[API.md](../API.md) §8  

备份内容边界见 [DST-OPS.md](../DST-OPS.md) §7。

## 8. 异常与边界

| 场景 | 行为 |
|------|------|
| 磁盘不足 | 创建失败，提示空间 |
| 恢复中 | 实例强制 stopped，完成后可启动 |
| 备份损坏 | 校验 hash，恢复前验证 |
| 运行中备份 | 警告可能不一致；默认建议停服 |

## 9. 验收标准

- [ ] 备份后删除测试文件，恢复后文件回来（[ACCEPTANCE](../ACCEPTANCE.md) F）。  
- [ ] 第 4 次备份删除最旧（若启用 3 份限制）。  
- [ ] 恢复确认文案含不可逆提示。

## 10. 不在本期范围

- 面板级全机备份（非实例级）
