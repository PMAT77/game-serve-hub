# FDS-03：DST 房间（Cluster）

- 里程碑：M1
- 优先级：P0
- 状态：规划态

## 1. 背景与目标

将房间级配置从隐式默认值升级为可视化可管理能力。

## 2. 角色与前置条件

- 角色：实例管理员
- 前置：实例已安装，具备房间配置目录

## 3. 功能范围

- 读取与编辑 `cluster.ini`
- 房间基础信息、网络与玩法设置

## 4. 功能清单

- 房间配置读取（Community）
- 表单保存与校验（Community）
- 配置模板库（Pro 规划）

## 5. 接口与输入输出（规划）

- `GET /app/instances/:instanceId/cluster`
- `PUT /app/instances/:instanceId/cluster`
- 输入：结构化配置对象
- 输出：配置内容与生效建议

## 6. 业务规则

- v1 保持 `1 实例 : 1 Cluster`。
- 运行中修改需提示重启影响。

## 7. 异常与边界

- 配置文件缺失 -> 提供默认模板重建
- 字段非法 -> 阻止保存并提示

## 8. 非功能要求

- 配置读写应原子化，避免文件损坏

## 9. 验收标准

- 配置可读可写且生效路径明确
- 与实例管理流程无冲突

## 10. 后续里程碑

- 多 Cluster 管理
- 与世界（Shard）联动编排增强
