## 录制与素材规范

- 分辨率 1920 × 1080、30 fps，终端字号 18，浏览器缩放 125%。
- 耗时的下载环节用加速播放并保留真实计时，不做跳过结果的剪辑。
- 演示服务器使用按量付费实例，录制完成后销毁；片中房间密码与管理员密码使用示例值，集群令牌一律不做展示。
- 界面截图放在 [`docs/images/`](images/)，界面改版时同步更新。

## 本项目当前不提供的能力

以下能力尚未提供，正在开发中，界面与文档都不要把它们当作可用功能：

- **在线玩家列表与踢人 / 封禁**：现在可以维护管理员、白名单与黑名单名单文件，但「谁在线、把他踢出去」需要在真实服务器上核对游戏返回的玩家字段后才能开工。
- **多用户与权限隔离**：后端已有账号与权限点，成员管理界面尚未提供。

下列能力已经可用，不要再说"没有"：

- 玩家名单管理（管理员 / 白名单 / 黑名单）与白名单预留位，入口在「房间管理 → 房间设置」的玩家名单区块；
- 实例目录的文件管理：浏览、文本编辑、上传、下载、重命名、删除，以及关键配置文件的直达入口；
- 世界维护：存档点查看、带回档前自动备份的回档、需输入实例名确认的重置世界；
- 环境自检与控制台日志落盘（可查看历史、可下载）。

另外两项属于产品边界，不在规划内：

- **Windows 部署**：本项目以 Linux 为目标平台，Windows 只用于本机开发调试，见[开发指南的平台定位](DEVELOPMENT.md#平台定位)。
- **多层世界**：当前支持地上与洞穴双分片，不支持两个以上的分片。

如果你需要在线玩家列表与踢人、多用户权限隔离，或者要在 Windows 上开服，**建议同时看看同类面板**，例如 [DMP 饥荒管理平台](https://github.com/miracleEverywhere/dst-management-platform-api) 或 [DST Admin Go](https://github.com/carrot-hu23/dst-admin-go)：它们的部署更简单，玩家管理更完整；本项目更适合已经有一台服务器、不想被云厂商绑定、希望自行长期维护的场景。
