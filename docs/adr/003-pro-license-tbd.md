# ADR-003：Pro 授权方案待定

- **状态**：待定（Proposed options）  
- **日期**：2026-05-18  
- **定稿目标**：M3 发布前（见 [TODO.md](../TODO.md)）

## 背景

产品采用 Community 开源 + Pro 商业版。需在实现 Pro 功能开关前选定授权与交付方式。

## 候选方案

### 方案 A：同包 + License Key（推荐优先评估）

- 同一 Docker 镜像/构建产物，通过 Key 或在线激活解锁 Pro。  
- **优点**：发行简单、用户自托管体验好。  
- **缺点**：密钥泄露与破解防护需投入。

### 方案 B：双仓库 / 双镜像

- Community 开源仓库；Pro 私有仓库或私有镜像 tag。  
- **优点**：代码隔离。  
- **缺点**：双 CI、合并与缺陷修复成本高。

### 方案 C：托管 SaaS

- 云厂商或官方托管控制面，用户不自托管面板。  
- **优点**：利于分润与运维。  
- **缺点**：与当前自托管主线偏离，适合 M4 云合作。

## 临时决策（开发用）

在定稿前，后端与前端使用环境变量：

```bash
GSH_EDITION=community   # 默认
GSH_EDITION=pro         # 开发/演示 Pro
```

Pro 功能点以 [TODO.md §8](../TODO.md#8-community--pro-功能对照表) 为准，代码中集中 `isProEdition()` 判断，避免散落魔法字符串。
