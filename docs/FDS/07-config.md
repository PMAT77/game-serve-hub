# FDS-07：配置中心

- 里程碑：M1
- 优先级：P0
- 状态：规划态

## 1. 背景与目标

提供统一配置管理入口，覆盖专用页面未承载的高级配置场景。

## 2. 角色与前置条件

- 角色：实例管理员
- 前置：实例目录可访问

## 3. 功能范围

- 配置读取、编辑、校验与保存
- 原始文本与结构化编辑协同

## 4. 功能清单

- INI/LUA 配置编辑（Community）
- 保存校验与生效提示（Community）
- 配置 diff 与导入导出（Pro 规划）

## 5. 接口与输入输出（规划）

- `GET /app/instances/:instanceId/config`
- `PUT /app/instances/:instanceId/config`
- 输入：目标路径 + 配置内容
- 输出：保存结果与生效建议

## 6. 业务规则

- 与 FDS-03/04/05 分工明确，避免重复编辑入口。
- 高风险配置变更需提示重启。

## 7. 异常与边界

- 解析失败 -> 禁止提交并标明位置
- 并发冲突 -> 需重新加载后提交

## 8. 非功能要求

- 配置写入需保证一致性

## 9. 验收标准

- 配置可正确读写并生效
- 非法配置不可入库/落盘

## 10. 后续里程碑

- 批量配置模板
- 多实例配置下发
