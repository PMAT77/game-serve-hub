# FDS-07：配置中心

- **里程碑**：M1  
- **优先级**：P0  
- **状态**：未实现

## 1. 背景与目标

在房间/世界专用页未覆盖的项，提供分组表单与原始编辑能力，统一读写实例目录内配置文件。

## 2. 用户角色与前置条件

- 实例已安装。  
- 与 FDS-03/04 分工：本模块处理**跨文件高级项**或**原始文本**，避免重复表单。

## 3. 名词

- **配置项**：映射到具体文件路径 + 键

## 4. 用户故事

1. **我希望**修改未在房间页暴露的 INI 项，**以便**微调规则。  
2. **我希望**保存前校验格式，**以便**避免写坏配置导致无法启动。

## 5. 页面与信息架构

实例 Tab「高级配置」：

- 左侧分组：房间、地表、洞穴、Mod、其他  
- 右侧：表单或 Monaco 原始编辑器（大段 lua）  
- 保存 / 保存并重启

**分工原则**：

| 配置 | 负责 FDS |
|------|---------|
| cluster.ini 常用项 | FDS-03 |
| server.ini / worldgen per shard | FDS-04 |
| modoverrides | FDS-05 |
| 其余 / 批量导入导出 | FDS-07 |

## 6. 功能点清单

| 功能 | 版本 |
|------|------|
| .ini 解析与写回 | Community |
| .lua 只读或受限编辑 | Community |
| 保存前语法/结构校验 | Community |
| 保存后重启确认 | Community |
| 配置导入/导出 zip | Pro / P2 |
| diff 对比 | Pro / P2 |

## 7. 数据与 API

- `server/src/infra/config-parser`（规划）  
- `GET/PUT /app/instances/:instanceId/config`  
- 请求体支持 `{ path, content }` 或结构化 patch

## 8. 异常与边界

| 场景 | 行为 |
|------|------|
| 解析失败 | 展示原始文本，标红错误行 |
| 并发保存 | 乐观锁或文件 mtime 检测 |
| 运行中保存 | 按项提示是否需重启 |

## 9. 验收标准

- [ ] 修改某 INI 键保存后文件一致，重启后生效。  
- [ ] 非法 ini 无法保存并提示。

## 10. 不在本期范围

- 非 DST 游戏配置（v1.x 适配器）

## 11. 依赖

- FDS-03、04 字段不冲突  
- [FDS-08](08-file.md) 可跳转同一文件
